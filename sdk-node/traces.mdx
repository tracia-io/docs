All trace operations are available under the `tracia.traces` namespace. Traces are automatically created when you run prompts and provide visibility into LLM usage, performance, and costs.

```typescript
import { Tracia, Eval } from 'tracia';

const tracia = new Tracia({ apiKey: process.env.TRACIA_API_KEY });

// List traces with filters
const { traces, nextCursor } = await tracia.traces.list({
  promptSlug: 'welcome-email',
  status: 'SUCCESS',
  limit: 20
});

// Get a single trace
const trace = await tracia.traces.get('tr_abc123def456');

// Submit an evaluation for a trace
await tracia.traces.evaluate('tr_abc123def456', {
  evaluator: 'quality',
  value: Eval.POSITIVE
});
```

## Types

### Trace

```typescript
interface Trace {
  id: string;
  traceId: string;
  promptSlug: string;
  promptVersion: number;
  model: string;
  provider: string;
  input: { messages: PromptMessage[] };
  variables: Record<string, string> | null;
  output: string | null;
  status: 'SUCCESS' | 'ERROR';
  error: string | null;
  latencyMs: number;
  inputTokens: number;
  outputTokens: number;
  totalTokens: number;
  cost: number | null;
  tags: string[];
  userId: string | null;
  sessionId: string | null;
  createdAt: string;
}
```

### Eval Constant

Use the `Eval` constant for binary evaluations:

```typescript
import { Eval } from 'tracia';

Eval.POSITIVE  // 1
Eval.NEGATIVE  // 0
```
